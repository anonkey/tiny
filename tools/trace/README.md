# Trace Viewer

> **Visualizes CPU execution from FST waveform files**

## Usage

```bash
python tools/trace/trace.py                          # default: test/tb_cpu.fst
python tools/trace/trace.py test/tb_cpu.fst --last   # show only last test run
python tools/trace/trace.py -n 20                    # show 20 cycles
python tools/trace/trace.py --skip-reset             # skip cycles during reset
```

## Output

Shows per-cycle execution state with register values:

```
=================================================================================================
  Test 8
Cycle    Time   PC   Instr  Decoded                   ALU   r0   r1   r2   r3   r4   r5   r6   r7
-------------------------------------------------------------------------------------------------
    0      25ns    0  0xA014  LDI  r0, 10             0x00    0    0    0    0    0    0    0    0
    1      35ns    1  0xA228  LDI  r1, 20             0x00   10    0    0    0    0    0    0    0
    2      45ns    2  0x0408  ADD  r2, r0, r1         0x1E   10   20    0    0    0    0    0    0
    ...
           185ns               --- final state ---             77   88   10   15   25  240   15    0
```

## Columns

| Column | Description |
|--------|-------------|
| Cycle | Clock cycle number |
| Time | Time in nanoseconds (relative to test start) |
| PC | Program counter value |
| Instr | Raw 16-bit instruction hex |
| Decoded | Human-readable mnemonic with operands |
| ALU | ALU result (combinational, from current instruction) |
| r0-r7 | Register file state (shows value *after* previous writeback) |

## Features

- **Test separation**: Detects reset boundaries, prints separator and header per test
- **Final state**: Shows register values after last instruction's writeback
- **Time reset**: Time display resets to 0 at each test boundary
- **Register reconstruction**: Reads individual DFF Q bits from FST to build register values

## Options

| Flag | Description |
|------|-------------|
| `-n N` | Show at most N cycles (default: all) |
| `--last` | Show only the last test run (after last reset) |
| `--skip-reset` | Skip cycles where `rst_n=0` |
| `-r` | (legacy, now always on) Show register state |

## Requirements

- `pylibfst` — Python bindings for FST waveform files
- FST file generated by cocotb/Icarus simulation (`$dumpfile("tb_cpu.fst")`)
